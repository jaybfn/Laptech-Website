# LAPTECH Website

Premium corporate website for LAPTECH — IT Infrastructure, Security, Networking & Power Solutions.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm run start` — production server
- `npm run lint` — ESLint

## Notes

Contact details, brand logos, and case studies use clearly marked placeholders until real LAPTECH content is provided.
